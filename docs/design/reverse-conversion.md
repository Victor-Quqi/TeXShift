# 反向转换设计

## 概述

实现 OneNote 富文本 → Markdown 的反向转换，通过元数据缓存机制保证还原精度。

## 按钮职责

| 按钮 | 方向 | 行为 |
|------|------|------|
| **转换** | 智能双向 | 有 MD 语法 → 正向转换；无语法但有有效缓存 → 反转 |
| **反转** | 强制反向 | 无论内容如何，尽力还原为 Markdown |

## 元数据缓存机制

### 存储位置

每个 OE 元素内嵌 Meta 标签：

```xml
<OE>
  <Meta name="texshift:type" content="code-block"/>
  <Meta name="texshift:lang" content="python"/>
  <Meta name="texshift:hash" content="a1b2c3d4"/>
  <T><![CDATA[...]]></T>
</OE>
```

### 按类型存储内容

| 类型 | 存储字段 | 原因 |
|------|---------|------|
| 代码块 | `type`, `lang`, `hash` | 代码文本可通过去除 HTML 标签恢复，只需存语言标识 |
| Mermaid | `type`, `source`, `hash` | PNG 无法反转，必须存完整源码 |
| LaTeX | `type`, `source`, `hash` | MathML 反转不完美，存完整源码保证精度 |
| 图片 | `type`, `alt`, `url`, `hash` | 嵌入后原始 URL 和 alt 文本丢失 |
| 引用块 | `type`, `hash` | 只需标记类型，内容从表格结构恢复 |

### 缓存过期检测

```
正向转换时：hash = MD5(渲染后的 <T> 内容)，存入 Meta
反转时：计算当前 <T> 内容的 hash，与存储的 hash 比对
  ├─ 匹配 → 缓存有效，使用存储的源码还原
  └─ 不匹配 → 缓存过期，尝试降级处理
```

## 转换按钮逻辑（保守策略）

```
扫描选区
    │
    ├─ 检测到 MD 语法 → 只转换有语法的段落，其他保持不变
    │
    └─ 未检测到 MD 语法
            │
            ├─ 有有效缓存 → 反转
            ├─ 部分缓存过期 → 提示用户确认
            └─ 无缓存 → 提示"未检测到可转换内容"
```

## 反转按钮逻辑

```
扫描选区
    │
    ├─ 有有效缓存 → 用缓存还原
    ├─ 缓存过期 → 尝试降级处理
    │     ├─ 代码块：strip HTML + 无语言标记
    │     ├─ LaTeX：尝试 MathML → LaTeX（未来）
    │     └─ 其他：结构解析
    └─ 无缓存 → 结构解析或保持原样
```

## 降级策略

| 元素 | 有缓存 | 缓存过期/无缓存 |
|------|--------|----------------|
| 代码块 | 完美还原 | 代码正确，语言丢失 |
| Mermaid | 完美还原 | 保持 PNG |
| LaTeX | 完美还原 | 尝试 MathML 反转 |
| 图片 | 完美还原 | 保持图片，无法还原语法 |
| 引用块 | 完美还原 | 结构推断（单列表格+背景色） |
| 标题 | - | quickStyleIndex 推断 |
| 列表 | - | List/Tag 元素推断 |
| 链接 | - | `<a href>` 解析，title 丢失 |
| 表格 | - | Table 结构解析 |

## 用户提示

| 场景 | 提示 |
|------|------|
| 混合内容（有 MD + 已转换） | "选区包含已转换内容，是否全部重新转换？" |
| 部分缓存过期 | "部分内容已被编辑，将尝试结构解析还原" |
| 无法还原 | "以下内容无法还原，已保持原样" |

## 实现阶段

```
阶段 1：正向转换写入缓存（MathBlock, CodeBlock, Mermaid, Image, QuoteBlock）
阶段 2：反转按钮 - 读取缓存还原
阶段 3：转换按钮 - 智能检测双向切换
阶段 4：降级 - 无缓存时的结构解析
阶段 5：MathML → LaTeX 反转（可选）
```

## 设置项

```json
{
  "cache": {
    "enabled": true,
    "maxSourceLength": 10000
  }
}
```

## 注意事项

1. **缓存粒度**：OE 级别，每个块独立，编辑只影响该块
2. **向后兼容**：旧版本转换的内容无缓存，按"无缓存"处理
3. **内联元素**：第一版暂不缓存内联代码/公式，依赖结构解析
4. **撤销兼容**：Meta 存在 XML 中，OneNote 撤销会同时恢复 Meta
