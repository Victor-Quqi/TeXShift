# 开发环境

要求 Windows 10/11、x64 OneNote 桌面版、.NET Framework 4.8 和 `global.json` 指定的 .NET SDK。Visual Studio 可选。

```powershell
.\build.ps1 -Target Build -Configuration Debug
.\build.ps1 -Target Test -Configuration Debug
```

脚本自动恢复 NuGet 和固定版本的 MathJax。构建本身不写注册表，也不需要管理员权限。

## Debug 加载项

首次使用或仓库移动后，关闭 OneNote，在管理员 PowerShell 中注册一次：

```powershell
.\setup\Register-TeXShiftDev.ps1 -Action Register
```

注册项位于 64 位 `HKLM\Software\Classes`，OneNote Addins 项位于当前用户 HKCU。`DllSurrogate` 是 OneNote Click-to-Run 环境下的必要配置。

后续直接重新构建并重启 OneNote。DLL 路径不变，无需重新注册。状态检查无需提权：

```powershell
.\setup\Register-TeXShiftDev.ps1 -Action Status
```

Debug 和安装版使用不同的 CLSID/ProgID。两者同时注册会显示两套 Ribbon；移除 Debug 版需关闭 OneNote，并在管理员 PowerShell 中运行：

```powershell
.\setup\Register-TeXShiftDev.ps1 -Action Unregister
```

## 本地 E2E

```powershell
.\tests\TeXShift.Tests.E2E\bin\x64\Debug\net48\TeXShift.Tests.E2E.exe convert --input "test.md" --output ".\TestResults"
.\tests\TeXShift.Tests.E2E\bin\x64\Debug\net48\TeXShift.Tests.E2E.exe reverse-xml --input-xml ".\TestResults\F04_Final_Page_XML_Basic_*.xml" --output ".\TestResults"
.\tests\TeXShift.Tests.E2E\bin\x64\Debug\net48\TeXShift.Tests.E2E.exe dump --hierarchy
.\tests\TeXShift.Tests.E2E\bin\x64\Debug\net48\TeXShift.Tests.E2E.exe dump --page "{page-id}" --output ".\TestResults\page.xml"
.\tests\TeXShift.Tests.E2E\bin\x64\Debug\net48\TeXShift.Tests.E2E.exe verify-restore --pages "{page-id-1},{page-id-2}"
```

`convert` 需要 OneNote；`reverse-xml` 可使用已有 XML 快照。两者向 stdout 输出 JSON，并以退出码表示结果。`dump` 只读取 OneNote XML，默认将原始 XML 写入 stdout。`verify-restore` 会反复关闭并重新启动 OneNote，只用于开发机上的主动检查。
